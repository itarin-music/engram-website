title: Keyboard shortcuts
description: Every keyboard shortcut in Engram, from switching sections to rating cards.

---

On a Mac, use <kbd>Cmd</kbd> wherever this page says <kbd>Ctrl</kbd>.

## Anywhere

| Keys | Does |
| --- | --- |
| <kbd>Ctrl</kbd> + <kbd>1</kbd> | Profiles |
| <kbd>Ctrl</kbd> + <kbd>2</kbd> | Decks |
| <kbd>Ctrl</kbd> + <kbd>3</kbd> | Notes |
| <kbd>Ctrl</kbd> + <kbd>4</kbd> | Study |
| <kbd>Ctrl</kbd> + <kbd>5</kbd> | Quizzes |
| <kbd>Ctrl</kbd> + <kbd>6</kbd> | Code |
| <kbd>Ctrl</kbd> + <kbd>7</kbd> | Chat |
| <kbd>Ctrl</kbd> + <kbd>8</kbd> | Timers |
| <kbd>Ctrl</kbd> + <kbd>9</kbd> | Import |
| <kbd>Esc</kbd> | Close a dialog |

Theme and Settings don't have number shortcuts. Use the sidebar.

## Notes

| Keys | Does |
| --- | --- |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> | Make a card from the selected text |
| <kbd>[</kbd><kbd>[</kbd> | Start a link to another note, with suggestions |

## Study

| Keys | Does |
| --- | --- |
| <kbd>Space</kbd> or <kbd>Enter</kbd> | Show the answer. Press again to rate **Good**. |
| <kbd>1</kbd> | Again |
| <kbd>2</kbd> | Hard |
| <kbd>3</kbd> | Good |
| <kbd>4</kbd> | Easy |
| <kbd>Z</kbd> | Undo the last rating |

## Quizzes

| Keys | Does |
| --- | --- |
| <kbd>1</kbd> to <kbd>6</kbd> | Pick a multiple choice answer |
| <kbd>Enter</kbd> | Check your answer |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Next question, after checking |

## Code

| Keys | Does |
| --- | --- |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Run the code |

## Chat

| Keys | Does |
| --- | --- |
| <kbd>Enter</kbd> | Send |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> | New line |

## Setup and splash

| Keys | Does |
| --- | --- |
| Any key | Skip the splash screen |
| <kbd>Enter</kbd> | Add a focus label as you type it |
