Engram is a desktop app for Windows, macOS and Linux. It's free, and you don't need an account to install or use it.

## 1. Download

Go to the [Download page](/download/). It suggests the right file for your computer and lists every other build too.

Not sure which file you need?

| Your computer | Pick |
| --- | --- |
| Windows 10 or 11 | **Installer (.exe)** |
| Mac with an M1, M2, M3 or newer chip | **Apple Silicon (.dmg)** |
| Mac with an Intel chip | **Intel (.dmg)** |
| Ubuntu, Debian, Mint | **.deb**, or the **AppImage** |
| Fedora, openSUSE | **.rpm**, or the **AppImage** |
| Any other Linux | **AppImage** |

To check which chip your Mac has, open the Apple menu and choose **About This Mac**. Look for "Chip" (Apple Silicon) or "Processor" (Intel).

## 2. Install

Every installer comes with step-by-step instructions on the [Download page](/download/#install). The short version:

- **Windows:** run the `.exe` and follow the steps.
- **macOS:** open the `.dmg` and drag **Engram** into **Applications**.
- **Linux:** install the `.deb` or `.rpm` with your software installer, or make the AppImage executable and run it.

### "Unknown app" warnings

Engram's installers aren't code-signed yet. Code signing is a paid certificate that tells your computer who published an app. Until Engram has one, Windows and macOS will warn you the first time you open it. That's expected. The [Download page](/download/#install) shows exactly how to get past it on each system.

If you'd like to be sure a file really came from Engram's official release, you can [check its SHA-256 checksum](/download/#verify).

## 3. Open Engram

Open Engram from the Start menu (Windows), the Applications folder or Launchpad (macOS), or your app launcher (Linux). The first time, a short setup appears. [First launch and setup](/docs/getting-started/first-launch/) walks you through it.

## Updating and uninstalling

Engram doesn't update itself. To update, download the newest version and install it over the old one. Your notes and cards are kept. See [Update Engram](/download/#update) and [Uninstall Engram](/download/#uninstall) for the details on each system.
