A profile is a separate workspace. Each profile has its own:

- notes folder (its "vault")
- decks, cards and review history
- quizzes, tutor chats and code exercise progress
- theme and tutor settings
- timer settings and session history

Switching profiles never merges or overwrites anything. Most people only need one, but a second profile is handy for keeping, say, a language and a programming course completely apart.

## Switch profiles

Use the **Profile** menu in the top bar, or open **Profiles** in the sidebar and press **Switch** on the one you want. If a timer is running, it's stopped and saved first.

## Create a profile

1. Open **Profiles** and press **New profile**.
2. Give it a name. Add focus labels if you like.
3. Pick a theme pack.
4. Choose where its notes are saved. The default is `Documents/Engram/<profile name>`. Press **Browse** to pick another folder.
5. Press **Create**. The new profile becomes the active one.

> **Tip:** keep vault folders inside your user folder, such as Documents. See [Troubleshooting](/support/troubleshooting/#a-profiles-folder-wont-open) if you choose a folder on another drive.

## Rename, relabel and add art

On the Profiles page:

- **Rename** changes the profile's name. The folder on disk keeps its original name.
- **Edit labels** changes its focus labels.
- **Art** (on the active profile) lets you pick an image for the profile card, up to 1.5 MB.

The active profile's card also shows how many notes, decks and cards it holds.

## Remove a profile

Press **Remove** on a profile and confirm.

On the desktop app, removing a profile **does not delete anything on disk**. Your notes and the profile's database stay in its folder, and Engram just stops listing it. To bring it back, create a new profile and point it at the same folder with **Browse**.

If you remove your only profile, the first-launch setup appears again so you can create a new one.

## Where imports go

Imports always go into the profile that is active when you start them. To import into a different profile, switch to it first.
